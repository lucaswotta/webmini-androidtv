# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub security advisories](https://github.com/lucaswotta/webmini-androidtv/security/advisories/new). Do not open a public issue.

Include the WebMini version, the device and Android version, the steps or page that reproduce the problem, and what an attacker gains.

In scope: ways for a page to open a second window, launch another app, load HTTP without the warning, start a download without confirmation, read app data, or bypass the network filter in a way that leaks data to a tracker.

Out of scope: ads that the filter lists do not cover, and vulnerabilities in Android System WebView itself, which go to the [Chromium security team](https://www.chromium.org/Home/chromium-security/reporting-security-bugs/).
